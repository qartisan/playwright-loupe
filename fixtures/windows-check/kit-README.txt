Loupe: do the rerun commands survive the Windows shells?
Throwaway, generated by fixtures/windows-check/build.mjs from the repository.
It only runs `playwright test --list`: no test runs, no browser is needed.

Needs: Node.js 22.12 or later. Git Bash and PowerShell 7 are tested when installed.

1. In any shell, from the folder holding the archive:

     tar -xzf loupe-windows-check.tgz
     cd loupe-windows-check
     npm install
     node setup.mjs

2. Automatic check, in every shell found:

     node check.mjs --measure

   The last line says PASS or FAIL. REQUIRED rows must have 0 bad. "measure" rows are
   information, not failures: literal letters, and commands above 8,000 characters.

3. By hand, in each shell: manual-paste.txt lists commands to paste as they are,
   adding " --list" at the end. A real clipboard paste is what users do.
